# Clube de Parcerias (saída pública)

Este repositório é a **saída** do Clube de Parcerias da Brazilian Nickel: a página em `docs/`
é **gerada automaticamente** a partir das parcerias que o RH publicou no painel interno.

- Não editar `docs/` à mão: a próxima geração sobrescreve.
- Aqui só entram os campos do card público (estabelecimento, categoria, condição, cidade,
  endereço, horário, canais do estabelecimento). Nada sobre quem indicou, contatos pessoais,
  motivos ou evidências: isso fica no ambiente interno.
- Publicado por GitHub Pages a partir de `main:/docs`.
